# Roles and permissions (RBAC)

## Base roles

There are four roles: `viewer`, `editor`, `admin` and `owner`. Each
service translates these roles into concrete permissions in its own table.

## Requesting access

Permissions are requested through the access form and approved by
the team lead. Administrator access is reviewed every quarter and
removed if it was not used.

## Principle of least privilege

Nobody gets the `admin` role for convenience. If you need a one-off
action, request temporary access of up to 8 hours.
